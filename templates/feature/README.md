# Molde de funcionalidade

Copie esta pasta para `src/features/<nome>`, remova `.template` dos arquivos e:

1. defina entidades e o contrato em `domain`;
2. implemente um adaptador em `services`;
3. crie hooks de consulta em `queries`;
4. exponha componentes públicos em `components`;
5. componha a tela correspondente em `src/app`.

Arquivos que não forem necessários devem ser removidos.
